# Bachelor Thesis — MARley

Working directory for the thesis write-up that accompanies the MARley
codebase.

## Contents

- `proposal/` — the original thesis proposal submitted to the supervisor.
- `thesis-template.md` — pointer to the UMR LaTeX template used for the
  final document.

The thesis itself is authored in Overleaf; this directory holds only the
small set of files that have to live in the repository (proposal,
bibliographic notes, supervisor correspondence copies if any).
